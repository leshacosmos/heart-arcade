# Великий покоритель сердца

Откройте `index.html`, чтобы попробовать оба кабинета на одном устройстве. В этом режиме переключатель «Демо» позволяет выбрать роль. Браузер сохраняет покупки, купоны и историю в IndexedDB. Стартовый баланс в примере — 18 сердечек.

## Локальная игра на компьютере

В каталоге приложения выполните `npm ci` при первом запуске и `npm start` для старта. Откройте http://127.0.0.1:4178. Выберите свой портрет и при первом входе задайте пароль. Для второго профиля нажмите «Выйти». В двух отдельных профилях браузера можно войти одновременно. Сервер слушает только этот компьютер. Роли, хеши паролей, история и купоны хранятся в каталоге `.local-data`, который исключён из Git.

## Подключение двух телефонов через Supabase

1. Создайте отдельный проект Supabase и выполните `database/001_game.sql`, затем `database/003_quests.sql` по одному разу в SQL Editor. Новая игра начинается с нуля.
2. В разделе Authentication включите вход по почте с паролем, выключите публичную регистрацию и вручную создайте две подтверждённые учётные записи. Каждый участник использует свой пароль.
3. Скопируйте идентификаторы этих пользователей из Authentication → Users. Выполните в SQL Editor следующий запрос, подставив реальные UUID.

   ```sql
   insert into heart_game.members (user_id, role) values
     ('UUID-ИГРОКА', 'player'),
     ('UUID-ЖЕНЫ', 'admin');
   ```

4. Заполните в `config.js` поля `url` (Project URL) и `publishableKey` (публичный ключ проекта). Клиенту нужен ключ с префиксом `sb_publishable_`.
5. Для GitHub Pages разместите в каталоге сайта `index.html`, `config.js`, `game.js`, `cabinet.js`, `quests.js`, каталоги `assets/quest-cards/` и `vendor/`, оба `avatar-*.png`, `manifest.webmanifest` и оба `icon-*.png`. Включите HTTPS. В публичной сборке используйте инициалы для статических PNG. В Supabase Storage создайте закрытый каталог `heart-portraits`, загрузите туда портреты `avatar-player.png` и `avatar-wife.png` и выполните `database/002_private_portraits.sql` один раз. После входа игра загрузит портрет из этого каталога.
6. Откройте один адрес с двух телефонов и войдите под разными аккаунтами. Жена начисляет сердечки и редактирует магазин. Игрок покупает награды. Оба видят историю и могут погасить купон. При открытом кабинете данные обновляются каждые восемь секунд и при возвращении во вкладку. Для значка на телефоне используйте команду браузера «На экран Домой» или «Установить приложение».

Браузер обращается к функциям базы, которые проверяют аккаунт и его роль. Покупка и выдача купона проходят в одной транзакции. Обеим учётным записям нужен интернет для работы с общей игрой. Демо хранит свою историю отдельно.

## Уведомления в публичной игре

Оба участника могут включить уведомления на своём устройстве. После входа откройте вкладку «Настройки», нажмите «Включить уведомления» и подтвердите запрос системы. Кнопка «Проверить» отправляет сообщение на это устройство. На iPhone с iOS 16.4 или новее откройте игру с экрана «Домой».

Для развёртывания на новом Supabase-проекте примените `database/004_web_push.sql` после миграции заданий. Затем примените `database/005_pair_play.sql` для подтверждения заданий, секретных миссий, желаний и быстрых сердечек. Опубликуйте `supabase/functions/heart-push/index.ts` под именем `heart-push` с проверкой JWT. Один раз отправьте из тестовой панели функции POST с телом `{"init":true}`. Функция создаст пару ключей VAPID на сервере. Повторная инициализация сохраняет существующую пару. Вместе с сайтом опубликуйте `push.js` и `push-worker.js` в корне приложения.
